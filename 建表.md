````markdown
# 课程作业：智能题库评测系统 数据库设计说明

本项目为个人课程作业，旨在实现一个“Agent 生成题目与题解 -> 用户解题提交代码 -> Docker 沙箱评测 -> Agent 给出反馈”的闭环系统。
为了降低开发复杂度，本项目采用**极简设计**，仅使用 **2 张核心表**，不使用复杂的外键约束和多对多关联。测试用例等多条数据直接以 JSON 格式存储。

## 数据库表结构设计

### 表 1：`problems` (题库表)

用于存储题目基础信息、所有测试用例以及标准参考题解。

| 字段名           | 数据类型     | 约束/说明                   | 备注                                                          |
| :--------------- | :----------- | :-------------------------- | :------------------------------------------------------------ |
| `id`             | INT / BIGINT | PRIMARY KEY, AUTO_INCREMENT | 题目唯一ID                                                    |
| `title`          | VARCHAR(255) | NOT NULL                    | 题目标题（如：两数之和）                                      |
| `difficulty`     | INT          | NOT NULL                    | 难度级别：0=简单, 1=中等, 2=困难                              |
| `description`    | TEXT         | NOT NULL                    | 题目详细描述，支持 Markdown 格式                              |
| `test_cases`     | JSON / TEXT  | NOT NULL                    | 测试用例集合，存储为 JSON 数组格式（详见下方结构说明）        |
| `reference_code` | TEXT         |                             | 标准参考题解代码（Agent生成），用于跟用户代码做比对和逻辑分析 |
| `tags`           | VARCHAR(255) |                             | 知识点标签，用逗号分隔（如：数组,哈希表,双指针）              |
| `created_at`     | DATETIME     | DEFAULT CURRENT_TIMESTAMP   | 记录创建时间                                                  |

**`test_cases` JSON 数据结构示例：**

```json
[
  {
    "input": "[2,7,11,15], 9",
    "output": "[0,1]",
    "is_example": true,
    "explanation": "因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。"
  },
  {
    "input": "[3,2,4], 6",
    "output": "[1,2]",
    "is_example": false
  }
]
```
````

_(说明：`is_example` 为 `true` 时展示给用户看，为 `false` 时作为 Docker 沙箱的隐藏评测点)_

### 表 2：`submissions` (提交与反馈记录表)

用于记录用户提交的代码、沙箱运行结果以及 Agent 给出的智能分析报告。

| 字段名         | 数据类型     | 约束/说明                   | 备注                                                                                             |
| :------------- | :----------- | :-------------------------- | :----------------------------------------------------------------------------------------------- |
| `id`           | INT / BIGINT | PRIMARY KEY, AUTO_INCREMENT | 提交记录唯一ID                                                                                   |
| `problem_id`   | INT / BIGINT | NOT NULL, INDEX             | 关联的题目ID（逻辑关联 `problems.id`，不建物理外键）                                             |
| `user_code`    | TEXT         | NOT NULL                    | 用户提交的源代码                                                                                 |
| `status`       | VARCHAR(20)  | NOT NULL                    | 沙箱评测结果状态：<br>AC (通过)<br>WA (答案错误)<br>CE (编译错误)<br>RE (运行错误)<br>TLE (超时) |
| `agent_report` | TEXT         |                             | Agent 生成的深度分析报告（包含：错误点、纠正逻辑提示、参考题解对比）                             |
| `created_at`   | DATETIME     | DEFAULT CURRENT_TIMESTAMP   | 提交时间                                                                                         |
